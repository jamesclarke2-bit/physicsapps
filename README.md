# Physics apps

Small interactive physics apps, served by GitHub Pages. Each app lives in its own folder
and is self-contained (plain HTML, CSS and JavaScript, no build step).

| Folder | App |
| --- | --- |
| `motion-graphs/` | Motion Graphs Mastery: s–t, v–t and a–t graphs, air resistance lab, learning journey |
| `cupcake-case-drop/` | Cupcake Case Drop: practical simulation on mass, area, air resistance, uncertainty and experiment design |

The landing page (`index.html`) links to each app. To add an app, create a new folder with
its own `index.html`, then add a card to the landing page.
| `force-mass-acceleration/` | Force, Mass and Acceleration: Trolley and hanging mass on a flat or tilted track: test F = ma and the SUVAT equations, with uncertainty and friction. |
| `half-life-isotopes/` | Half-life and Choosing Isotopes: Watch nuclei decay at random, read half-lives from graphs, then choose the right isotope for medicine, industry and dating. Marked questions with progress saved. |
| `fission-reactor/` | Nuclear fission reactor: Run a reactor: control rods, chain reaction, energy transfers to electricity, and the waste debate. |
| `ramp-practical/` | Ramp Practical: Design and validate: v² = u² + 2as and a = g sin θ for a trolley on a ramp, with uncertainty analysis, raw and straight-line data. |
