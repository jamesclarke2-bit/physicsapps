# Physics apps

Small interactive physics apps, served by GitHub Pages. Each app lives in its own folder
and is self-contained (plain HTML, CSS and JavaScript, no build step).

| Folder | App |
| --- | --- |
| `motion-graphs/` | Motion Graphs Mastery: s–t, v–t and a–t graphs, air resistance lab, learning journey |
| `cupcake-case-drop/` | Cupcake Case Drop: practical simulation on mass, area, air resistance, uncertainty and experiment design |

The landing page (`index.html`) links to each app. To add an app, create a new folder with
its own `index.html`, then add a card to the landing page.
