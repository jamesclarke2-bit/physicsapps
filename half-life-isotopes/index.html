          About this model. Each nucleus decays at a random time, so a small sample is a little uneven and a large one follows the smooth halving curve. The half-life is the time for the activity (or the number of undecayed nuclei) to halve. Half-lives are rounded GCSE values. A reading read from a graph has a fixed uncertainty, so a longer interval has a smaller percentage uncertainty. Uncertainty in a few readings is half the range. A fault that affects every reading, such as forgetting background, stays wrong however often you repeat it.
